## Chương 5: Domain Event

Đây là trái tim của **Event-Driven Architecture**.

Chúng ta **không** tư duy theo hướng:
User gọi API ➔ Update Database

Mà tư duy theo các sự kiện đã xảy ra (**Domain Events**):

* Member Created
* Workspace Created
* Project Created
* Task Assigned
* Task Completed
* Document Uploaded
* Document Indexed
* Comment Added
* Notification Sent
* Automation Triggered
* AI Summary Generated

> **Cốt lõi:** Toàn bộ hệ thống sẽ xoay quanh Event.
